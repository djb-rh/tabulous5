Tabulous5

Firmware @VER@: a party, puzzle and emulation console for the M5Stack Tab5 — nine games from PhraseCraze to Doom. Source, docs and licence (GPL-3.0) on GitHub.

1. Install the firmware

  1. Use Chrome or Edge on a desktop (Web Serial is needed; Safari and Firefox do not have it).
  2. Connect the Tab5's USB-C port to the computer, then press the Tab5's power button once with the cable attached. If it is already running Tabulous5 it keeps its USB data lines off unless it was started on a computer, and that press is a restart.
  3. Click Install below and choose the Tab5's port (it is usually called USB JTAG/serial debug unit).
This browser cannot flash devices. Use Chrome or Edge on a desktop computer. The page must be opened over https.

If no port shows up or the install fails: hold the Tab5's power button until the screen goes dark to put it in download mode, then try again. Installing replaces whatever firmware the Tab5 had; the word packs, sounds and settings it keeps on its own flash are set up fresh on first boot.

2. Games from a card

  1. The party and puzzle games need nothing more. The emulators and Doom read from a FAT32 microSD card: folders /nes, /gb, /arcade, /snes and /doom, with your own files in them. Nothing of that kind is shipped.
  2. Word packs and sounds can be edited from a browser: SETTINGS → EDIT CONTENT OVER WI-FI, once the network is named in the firmware's secrets.h or by joining the console's own hotspot.
  3. Everything else is in the README.
